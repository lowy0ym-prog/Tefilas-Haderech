# Tefilas Haderech

An offline-first Android starter app for the Ashkenaz text of Tefilas Haderech.

## First build

This first milestone provides a readable prayer screen, adjustable text size, and a manual reminder notification. It does **not** yet perform reliable automatic travel detection or determine halachic boundaries. Those require careful testing and a configurable halachic policy.

## Build an APK

Push to `main` and open **Actions → Build Android APK**. When the workflow finishes, download the `tefilas-haderech-debug-apk` artifact.

## Important

Please have the exact nusach and punctuation reviewed by a trusted Ashkenaz siddur/rabbinic source before relying on the prayer text. Notifications and location permissions are optional; the prayer can always be opened manually.
